## 三、样张生成器设计（`tools/gen_fixtures/main.go`）

**核心思想**：**不真跑构建**（题面红线：工具本身不跑构建；但样张生成器需要"两次构建的等效物"）。做法是**程序化合成**——同一份虚拟源码树，用两组受控参数各写一次产物：

```
inputs (固定表)                     ┌──> left  产物（目录/tar/tar.gz/zip/whl/jar）
SOURCE_DATE_EPOCH, umask, uid, ────┤
gid, build_dir, toolchain, ────────└──> right 产物（仅差注入项）
compression_level, entry_order
```

**纪律**：

1. **不读系统时钟**：时间戳只从 `{0, 1700000000, 1700003600}` 取（`data/README.md` §三）。
2. **不读环境变量**：唯一输入是 `--out`（默认 `data/fixtures`）与 `--only <case>`（部分生成）。
3. **部分运行不改全集清单**（阶段 1 纪律）：`--only` **绝不**写 `data/fixtures/manifest.json` 的条目集合之外的清理动作；清单写盘条件 = `only == ""`。常驻测试断言"`--only` 运行后入仓文件逐字节不变"。
4. **确定性**：合成内容用固定字符串表 + `sha256` 派生填充（不用 `math/rand`；用 `sha256(seed‖index)` 取字节，跨语言/跨版本稳定）。归档里所有头部字段显式赋值（不依赖库默认值）。
5. **`--check` 模式**：生成到临时目录 → 与 `data/fixtures/` 逐字节比对 → 一致 exit 0，不一致 exit 1 并列出差异文件（"重生成位级一致"守门）。
6. **zip 跨平台冻结**：`zip.FileHeader` 显式设置 `CreateSystem`、`ExternalAttrs`、`Modified`，压缩用 `zip.Deflate` 但**压缩级别固定**（`flate.BestCompression`）；若发现跨平台漂移，退化为 `zip.Store`（与论文工作台的处置同源，见方法论 references）。
7. **真值只存输入与期望**：`expect.json` 里**不得出现** `observed_*` 一类字段；期望值必须可由输入独立复算（例：`counts.T1 = 条目数`，而不是"我跑了一遍工具记下来的"）。

## 四、真值纪律

| 纪律 | 落地 |
|---|---|
| 真值只存输入与期望 | `expect.json` 只有 `inputs`（注入参数）与 `expect`（分类/最小集/退出码/residue 的**范围或精确值**） |
| 期望可由输入独立复算 | 例：`c09` 的 `expect.minimal_cause_set == ["T1","T2"]`——由"注入项恰好是 T1+T2"直接推出，不由工具产出 |
| 每份 golden 附生成命令 + 手工复现命令 | `data/golden/**/README.md`，形如 `go run ./tools/gen_fixtures --out data/fixtures` 与 `cmp`/`sha256sum` 复算 |
| residue 有手工计数 | `c11`/`c12` 的 `expect.residue_bytes` 由 `cmp -l` 手工计数记录在该 case 的 README |
| 冻结件禁手改 | `data/golden/**` 与 `data/fixtures/**/*.tar*` 由生成器产出；改生成器 → 整目录重生成 + `--check` 绿 |

## 六、重建判据

```bash
go run ./tools/gen_fixtures --out data/fixtures --check   # 必须 exit 0 且输出 "13 cases, 0 diff"
go test ./...                                              # golden 断言全绿
git status --short                                         # 必须为空（生成器无副作用）
```

三台机器（不同路径/时区/平台）跑同一条 `--check` 必须都绿——跨平台一致性只在 CI 矩阵（windows-latest / ubuntu-latest）验证，本机结论不冒充跨平台结论（写入 `plan/06` 风险登记 R3）。
