## 二、决策记录（补充 `plan/00` §二；只追加）

| 日期 | 决策 | 理由 |
|---|---|---|
| 2026-10-20 | 布局门用 **Node（`tools/check-sprint-layout.mjs`）** 而非 Go | 门要能在**没有 Go 工具链**的机器上跑（接手/审查场景）；npm 零依赖 + Node 在 CI 镜像预装。判据集与语言无关，Go 项目照样能跑 |
| 2026-10-20 | `go.mod` 声明 `go 1.22`，CI 矩阵用 Go 1.22 / 1.24 | 与 `go.mod` 下限一致，避免"本机高版本写出的语法在 CI 低版本炸" |
| 2026-10-20 | 新增第 13 组样张 `c13-signature`（T10） | 题面要求"不允许有类别没有样张"，而原 12 组不含 T10 |
| 2026-10-20 | `--budget` 只接受逗号分隔 + `all` | 阶段 7 出口门①实测过的坑：文档写多值、parser 加 `choices` 直接拒。单值/多值/`all` 三形态各一条测试 |
| 2026-10-20 | 退出码 1（用法错误）与 2（仅元数据）严格分家 | 2 是业务语义，不能被 argparse 类错误占用；CLI 层统一把用法错误映射到 1 |
| 2026-10-20 | 目录条目 `kind=dir` 参与 align、不参与 facts | 目录无头部可抽；但仍需计入 ADDED/REMOVED/RENAMED 计数 |
| 2026-10-20 | 单条目上限 `--max-entry-bytes` 默认 256 MiB，超限 exit 1 并指名 | 安全阀必须可见（会被排除的件要显式报出），不静默丢弃 |
| 2026-10-20 | 新增第 14 组样张 `c14-pax-unknown`（未知 PAX keyword） | `raw_header_sha256` 的兜底纪律需要一个可机械验收的反例（plan/00 §二 的决策）；它同时给 T7 增加一条归档头扩展样本 |
| 2026-10-20 | **不代办建仓**：`gh repo create` / `git remote add` / 首推都是**外发动作**，留到 M6 由用户确认后执行 | 本地仓库已具备"可直接上传"的形态（干净 clone 可离线构建、CI 配置就位、脱敏扫描通过），但"是否公开、仓库名、署名"由用户拍板 |

## 三、风险登记

| # | 风险 | 影响 | 缓解 |
|---|---|---|---|
| R1 | **无远端时 CI 从未实跑** | "本地绿"不代表 CI 绿 | 所有 CI 类 DoD 写"本地等价校验（未接远端）"；M6 首推后据实补记 |
| R2 | **Go 工具链在本机为本次新装** | 首棒若装失败，后续无法验证 | 已落 `plan/00` §八 安装记录 + 校验命令；`go build` 在 M0 实跑过 |
| R3 | **跨平台归档字节漂移**（zip `create_system`、deflate 版本） | golden 在 Linux 上红 | 生成器显式设置全部头部字段；必要时退 `zip.Store`；CI 双平台 `--check` |
| R4 | **合成样张覆盖不了真实产物形态** | 分类法在真实 tarball 上可能落到 T12 | README 与 `plan/06` 明写"v0 只在合成样张上验证"；T12 是显式出口而非失败 |
| R5 | **最小集搜索 2^12 的耗时** | 大样张上可能慢 | 上界 4096 候选 × 一次摘要；M4 实测回填；不剪枝（保可复算） |
| R6 | **`--budget` 语义被误用为"忽略差异"** | 用户以为放行=没差异 | 报告里仍逐条列出被放行的差异与计数；README 明写"放行≠消失" |
| R7 | **脱敏漏项**（绝对路径/主机名/用户名） | 发布不可用 | `-trimpath` + 报告只写 basename + 静态黑名单 `os.Hostname`/`os/user` + M6 扫描 |
| R8 | **T9/T10 的归一化要重写 ELF 节表**（删段会移位） | M3 可能做不出"删段后字节相等" | 样张的 ELF 由生成器手写、节布局固定，归一化可按同一布局重建；若仍不可行，M3 收尾时改判 `c13` 的期望并在留档说明（不静默降低标准） |
| R9 | **tar.gz 的 deflate 字节随 Go 版本漂移** | CI 矩阵（1.22/1.24）的 `--check` 可能红 | **已按预案关闭（2026-10-20，首推两次实测暴露）**：`flate.HuffmanOnly` 的末块编码在 go1.22/1.24 vs go1.27 仍漂（1690 vs 1687 字节）；终版处置 = 生成器手写 RFC 1951 stored 块（BTYPE=00），逐字节确定、与任何 Go 版本无关，go1.22/1.24/1.27 三工具链 `--check` 实测全绿 |
