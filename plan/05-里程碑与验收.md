1. DoD 逐项验证（命令 + 输出留档）。
2. 回写状态：`plan/00` §六 表、本文件 §一 表、`README.md` 状态表 —— **三处同一次提交**。
3. `plan/06` 缺口表：关闭的缺口移出（不点名已 ✅ 的里程碑文件）。
4. 写 `plan/HANDOFF-M<next>.md`（七节）。
5. `git status --short` 干净 → commit（信息用"追加/补记/对账/复核"语义）。
6. 有远端则 push，等 CI 绿，**据实补记 run id**。
